Use case: ui-mockup. Create one high-fidelity design board for a suite of fullscreen French reMarkable Paper Pro tablet apps. Landscape board showing four equal portrait 3:4 screens side by side, labeled beneath reMoodle, reAgenda, reCalc, rePDF. Screens only, no tablet hardware, no perspective, no marketing headings. Each interface must convincingly resemble the authentic reMarkable tablet OS: pure white paper, black ink, fine 1px straight divider lines, spacious plain lists, serif section headings resembling reMarkable Serif Small and modest sans serif body type resembling reMarkable Sans. Square-corner primary black buttons only where useful, secondary actions plain text or fine outline symbols. At equivalent logical resolution 810x1080 use 24px serif title, 14px body, 11px captions, 48px high controls, 24px icons, 40px outer margin. All interface content in French, restrained small typography and huge generous whitespace. Panel 1 reMoodle file list: top-left subtle back chevron, heading 'Électronique', top-right search and refresh symbols. Below 3 thin divided rows with outline page icons, 'Chapitre 3 — Amplificateurs' caption 'PowerPoint · 24 diapositives', 'Travaux dirigés' caption 'PDF', 'Schémas de référence' caption 'PDF'. Trailing arrow at each row. No cards, no gray background boxes. Panel 2 reAgenda heading 'Lundi 7 septembre', discreet navigation arrows and 'Aujourd’hui', tabs 'Jour  Semaine  Mois' with selected Jour thin underline. A vertical schedule list: '08:00–10:00' beside 'Électronique' and smaller 'Salle B204'; '10:15–12:15' beside 'Mathématiques'; '14:00–16:00' beside 'Physique'. Outline note icon trailing each event. Panel3 reCalc small heading 'reCalc', history icon and 'DEG' top. Large blank working area with centered mathematical expression stacked fraction 1 over 3 plus 1 over 6, equals 1 over 2. Bottom keypad minimal rectangular grid with thin lines, visible digits and math functions, 6 columns. Only equals key solid black. No useless labels or help copy. Panel4 rePDF full-page academic PDF containing a few realistic equations and simple scientific line drawing, content occupies nearly entire screen, slim unobtrusive bottom floating white toolbar with previous arrow '3 / 24' next arrow and close symbol. Consistent native tablet style across all screens, no color, no drop shadows, no rounded cards, no heavy outer frames. This is a design concept, not claim of actual screenshot.
